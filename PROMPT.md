Активный пункт подсвечивается на своей странице (оранжевая полоска). Сейчас `li.active::after` позиционируется абсолютно без `position: relative` у родителя, проверь.

`.container` -> `max-width: 1400px; width: 100%; padding: 0 20px`. Брейкпоинты 1024 / 768 / 480:
